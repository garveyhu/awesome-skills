# 台账 + 迭代日志模板

## `01-台账.md`（backlog · 每轮选最高优先）

> BabyAGI 优先级表的文件版。开放项带**优先级 + 价值 + 状态 + 依赖**四字段（防挑软柿子靠「价值」字段 + §6.4 规则）。完成项打勾/归档·新发现追加。顶部留一行「当前轮次」滚动摘要。

```markdown
# 01 · <任务名> 台账（loop 每轮更新）

> 开放项 + 状态 + 优先级。每轮选最高优先未完成项推进，完成打勾，新发现追加。

## backlog
| # | 开放项 | 价值 | 优先级 | 状态 | 依赖 |
|---|--------|:--:|:--:|------|------|
| 1 | <做什么> | 🔴高 | P0 | ⚪未开始 / 🟡进行 / 🟢✅完成 | <#x 或 无> |
| 2 | ... | 🟡中 | P1 | ... | ... |

## 累计
- 当前轮次：<N>（**<本轮一句话摘要>**）
- 北极星：<一句话>
- <关键里程碑滚动摘要·新的加最上>
```

**反挑软柿子规则**：某高价值项（🔴）连续 N 轮没被选 → 本轮**强制处理**、或在日志显式记「为何跳过」。优先级决策要独立于「谁来执行」。

## `02-迭代日志.md`（言语反思记忆 · append-only 倒序）

> Reflexion 的外部化——每轮记「做了什么 + **验证门真实结果** + 坑 + 下一步」。**最新在最上·永不改写旧条目**（改写=语义漂移）。`date` 取时间。

```markdown
# 02 · <任务名> 迭代日志（loop 每轮倒序追加）

> 每轮结束追加：date 时间 · 轮次 · 做了什么 · 验证结果 · 坑 · 下一步。最新在最上。

---

## 轮次 N · <一句话标题> · <YYYY-MM-DD HH:MM>

**触发**：<为什么做这件>。
**做了什么**：<动作>。
**★验证门结果**：<跑了什么·真实输出·过/不过>（贴真实输出·不报自评）。
**多智能体评估**：<建造/审视/对抗 各自结论>。
**诚实标完成度**：<这项做到几成·坑·没做到的说没做到·负面结论照实记>。
**剩**：<下一步/开放项>。

---

## 轮次 N-1 · ...
```

> 写日志的诚实底线：**负面结论（试了不成立）是有价值的 learning，照实记，别藏**。「试了 X·验证门抓到 Y·撤回·结论 Z」比假装成功有价值得多。
