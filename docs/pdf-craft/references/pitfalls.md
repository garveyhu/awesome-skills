# 踩坑账

**全是真撞过的**，不是理论上可能出问题的清单。新踩到坑就往这里追加。

---

## 1. `justify` + 窄容器 = 字距爆散 ⭐ 最阴

**症状**：表格单元格里出现「唯 一 写 入 路 径」这种被拉开的字。

**原因**：`body { text-align: justify }` 会被表格继承。当一行文字后面跟着**不可断开的长 token**（代码名 `EditTransaction`、英文词、URL），浏览器为了两端对齐，把前半行的字距强行撑满整行。

列越窄越容易触发，所以表格是重灾区。

**修法**：

```css
table { text-align: left; }              /* 表格一律左对齐 */
code  { overflow-wrap: anywhere; }       /* 允许在代码名前后断行 */
```

正文保持 `justify` 没问题——栏宽足够，撑不散。

---

## 2. 引号批量替换会配对错乱

**症状**：一行里有两对引号时，替换完变成 `全国"AI+OPC“创业` —— 左右引号张冠李戴。

**原因**：贪婪正则跨越了多个引号对。

**修法**：替换后必须校验 ①全文 `“` 与 `”` 数量相等 ②**逐行**检查配对。`lint.mjs` 两项都查。发现不配对的行手工修，别再跑一次正则。

---

## 3. 同一个数字散落多处，改漏一处就穿帮

**症状**：改了收入预测，但摘要里、柱状图标注里还是旧值。

**修法**：改完立刻 grep 旧值扫全库：

```bash
grep -rn "225,000\|22.5 万\|旧数字" --include="*.md" --include="*.html" .
```

**财务表还要验算自洽**：分项之和 = 合计、利润 = 收入 − 成本。会有人拿计算器验。

---

## 4. Markdown 源与 HTML 排版版的双份真相源

**症状**：内容同时存在 `xxx.md` 和 `xxx.html` 两份，改一处忘另一处。

**为什么会这样**：md 表达不了封面、框注、自绘图表，复杂文档必须走 HTML；但 md 又是给人读/给 AI 改的方便格式。

**处理**：认清哪份是真相源，另一份降级。或者接受双份但**每次改完 grep 关键数字比对**——这比重构成单一源便宜得多，且防住了唯一真正致命的风险。

---

## 5. `preferCSSPageSize` + `@page :first { margin: 0 }`

首页边距为 0 时，页脚**没有空间显示**，所以封面自动不显示页码。

这**正是想要的效果**（封面不该有页码），但要知道是有意为之——别以为是 bug 去"修"。

---

## 6. 网络字体在离线渲染必失败

`@import url(https://fonts.googleapis.com/...)` 在 headless Chrome 渲染 `file://` 时**静默 fallback**，不报错，但字全变样。

只用系统字体。字体栈带兜底。

---

## 7. 表格 / 代码块被撕成两页

```css
table, pre, figure, .box { page-break-inside: avoid; }
h2, h3, h4 { page-break-after: avoid; }   /* 标题别孤零零留在页尾 */
```

超过一页的长表格另说——那种要么拆表，要么接受跨页并考虑重复表头。

---

## 8. PDF 出来了没法直接看

macOS 默认没有 poppler，Read 工具渲染不了 PDF 页面。

**用 `preview.mjs`**：按 print 媒体渲染 HTML 分段截图，效果等价。验单个表格/图表用 `--el ".selector"` 更快。

看完删图：`rm -f preview-*.png`

## 9. 半角括号夹中文

`(2026年)` 在中文正文里应写 `（2026 年）`。不致命但显得糙，`lint.mjs` 报 INFO。

代码、英文语境里的半角括号是对的，按语境判断。
