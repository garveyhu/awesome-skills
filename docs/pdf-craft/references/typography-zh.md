# 中文排版规范（印刷向）

排中文 PDF 时最容易露怯的地方。**动手前过一遍，交付前再过一遍。**

---

## 1. 引号

| 场景 | 用什么 | 说明 |
|---|---|---|
| 中文正文引用 | `“ ”` `‘ ’` | **绝不用 `" "` `' '`**——英文直引号在中文里一眼就露怯 |
| 书名、报告名、政策文件名 | `《 》` | 《杭州市…行动计划》 |
| 代码、路径、标识符 | `` ` ` `` 或 `<code>` | 保持 ASCII 原样 |

港台的直角引号 `「 」` 在大陆正式公文里**不标准**，内部文档可以用，对外材料别用。

**批量替换要当心**：一行里有两对以上引号时，贪婪正则会配对错乱。替换后必须校验左右引号数量相等，且**逐行**检查配对。

---

## 2. 数字：中文数字 vs 阿拉伯数字

| 场景 | 用什么 | 例 |
|---|---|---|
| 公文封面、落款日期 | 中文数字 | 二〇二六年七月二十九日 |
| 章节序号（公文体） | 中文数字 | 一、（一）1. |
| 章节序号（技术报告体） | 阿拉伯数字 | 1　1.1　1.1.1 |
| 数量、金额、比例、年份区间 | 阿拉伯数字 | 300 万元、42%、2026—2028 年 |
| 表格内所有数字 | 阿拉伯数字 + 等宽字体 | 需 `font-variant-numeric: tabular-nums` 才能列对齐 |

注意"二〇"用的是汉字零 `〇`（U+3007），不是字母 O，也不是数字 0。

---

## 3. 中西文混排

- 中文与西文/数字之间**加一个空格**：`营收达到 300 万元`、`使用 TypeScript 开发`
- 与标点之间**不加**：`（2026 年）` 不写成 `（ 2026 年 ）`
- 百分号、货币符号紧贴数字：`42%`、`¥299`

---

## 4. 段落

| 版式 | 首行缩进 | 段间距 |
|---|---|---|
| 公文 / 正式文件 | `text-indent: 2em` | 小（3mm 左右） |
| 提案 / 技术报告 | 不缩进 | 大（靠间距分段） |

**两者不可混用**——同一份文档里既缩进又靠间距，会显得没规矩。

标题、列表项、表格单元格、框注内的段落**一律不缩进**（`text-indent: 0`）。

---

## 5. 标点

- 中文正文一律**全角**标点：`，。；：？！（）《》`
- 破折号用 `——`（两个），不是 `--` 或 `—`
- 省略号用 `……`（六点），不是 `...`
- 连接号：数字区间用 `—`（如 2026—2028），范围用 `~` 或 `～`（如 5~20 万）
- **超大标题里的句号要缩小**：`.dot { font-size: .5em }`，否则一个句号和汉字一样大，很笨重

---

## 6. 表格

正式文档用**三线表**（顶线粗、表头下线细、底线粗，行间无竖线）：

```css
thead th { border-top: 1.5px solid #000; border-bottom: .75px solid #000; }
tbody tr:last-child td { border-bottom: 1.5px solid #000; }
/* 行间只用极淡横线或不用，绝不画竖线 */
```

- 表标题在**上方**（`caption-side: top`），图标题在**下方**
- 编号按「章-序」：表 3-1、图 5-2
- 数字列**右对齐 + 等宽字体**，文字列左对齐
- 单位统一写在表标题里（「单位：元」），不要每格都带

---

## 7. 字体

**只用系统字体，绝不引网络字体**——离线渲染时会静默 fallback，字全变样还不报错。

macOS 可用：

| 用途 | 字体 |
|---|---|
| 中文正文/标题 | `PingFang SC`（黑体系，屏幕与打印都清晰） |
| 中文宋体（更传统的公文观感） | `Songti SC` / `STSong` |
| 数字、代码、标签 | `JetBrains Mono`（若已装）→ `SF Mono` → `Menlo` |

字体栈里**永远带兜底**：`"PingFang SC", "Heiti SC", "Microsoft YaHei", sans-serif`（最后一项让 Windows/Linux 也能开）。

---

## 8. 避头尾

标点不应出现在行首（如 `。`）、开引号不应出现在行尾。Chrome 的中文避头尾支持有限，长文档偶尔会遇到。

发现时的处理：调整该处措辞或用 `&nbsp;` 绑定，不要为此改全局行宽。

---

## 9. 交付前逐条确认

- [ ] 全文无英文直引号，弯引号左右配对
- [ ] 中文数字/阿拉伯数字的分工正确（日期 vs 数量）
- [ ] 中西文之间有空格
- [ ] 缩进方式全篇统一
- [ ] 表格是三线表，数字列右对齐且等宽
- [ ] 表在上、图在下，编号连续
- [ ] 字体栈无网络字体、有兜底
- [ ] 中文词没有被容器切断
