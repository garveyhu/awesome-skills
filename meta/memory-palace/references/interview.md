# interview — 深度访谈，把「你是谁」问出来

目标：通过结构化、能**挖掘深**的提问，把用户的身份/品味/原则/项目变成可操作的记忆，写进 `00-RULES/` 与 `01-PROJECTS/`。

## 三条铁律

1. **一次只聊一层**，聊透、当面确认后再写盘，不一口气抛 50 题。
2. **每个回答后追问**，挖到**可操作的具体**、不停在抽象口号。四把追问铲：
   - 「**为什么**？」（动机/价值观）
   - 「**举个具体例子**？」（把抽象落到事实）
   - 「**反例是什么 / 什么时候不适用**？」（边界）
   - 「**上次这条救了你 / 坑了你是什么时候**？」（证据，最能挖出真偏好）
3. **写盘前复述**给用户确认，落到对应文件、带 frontmatter（`confidence` 按证据强度给）。**绝不编造**用户没说的。

## 分层提问（按这个顺序，逐层做）

| 层 | 种子问题 | 追问方向 | 写到 |
|----|---------|---------|------|
| **身份** | 你是谁？在打造什么？ | 不可替代性在哪？别人抄不走的是什么？ | `00-RULES/who-i-am.md` |
| **声音** | 你希望 AI 跟你说话、帮你写东西是什么调？ | 给我看一段你**满意**的、和一段你**受不了**的文字？禁用词？ | `00-RULES/voice.md` |
| **品味/反模式** | 什么东西一出现你就觉得「廉价 / AI 味 / 不专业」？ | 具体到视觉/措辞/结构的例子 | `00-RULES/cliche-ban-list.md` |
| **工作偏好** | 你的工具默认、决策习惯是什么？ | 最近一次你纠正 AI 是为什么？你希望它默认怎么做？ | `00-RULES/preferences.md` |
| **铁律** | 有没有你**绝不妥协**、反复坚持的原则？ | 这条是怎么来的（踩过什么坑）？什么情况例外？ | `00-RULES/_principles/<名>.md` |
| **项目** | 你手上在做哪些事？ | 每个项目的关键约束/已敲定的决定/你打回过 AI 什么产出？ | `01-PROJECTS/<名>/{_index,decisions,feedback}.md` |

## 节奏

- 开场先问用户想先聊哪层（或按上表顺序）。
- 每层：种子问 → 至少 2 轮追问挖深 → 复述「我打算这样记，对吗」→ 确认后写盘。
- 一层写完问要不要继续下一层，允许随时停。
- 写身份/铁律层时 `confidence` 给 medium（待飞轮验证再升 high）；用户斩钉截铁的可给 high。

## 纪律
- 深度优先于覆盖：宁可把一层挖透，不浅尝五层。
- 写盘只写用户**确认过**的；模糊的标「待确认」。
- `00-RULES/_principles/` 是最高法律，写新原则前额外确认一次。
