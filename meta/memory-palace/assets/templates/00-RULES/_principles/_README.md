# _principles · 分级跨领域原则

> 每条原则一个文件。这是最高层的「铁律」沉淀区。

## 铁规则

- **agent 永远不能直接往这里写**。新原则只能经 `04-FEEDBACK` 蒸馏出候选 → 主人在 `/memory-palace review` 审批 → 才晋升到此。
- 这保证最高法律**永远是主人亲自签字的**，不被任何模型幻觉污染（吸收 open-second-brain「内核不调 LLM」哲学）。

## 一条原则文件长什么样

```
---
title: <原则名>
type: principle
scope: global
status: active
confidence: high
created / updated / last_confirmed
source: [促成它晋升的证据]
---

# 原则：<一句话>
- 为什么（动机 / 踩过的坑）
- 怎么应用（具体到行为）
- 边界 / 例外
```
