# 梦境日记 · DREAMS

> 每次 `distill`（蒸馏）和 `promote`（晋升）都在这里留一条，供复查与回滚。
> 吸收 OpenClaw `DREAMS.md` 可解释性 + open-second-brain 可审计哲学：记忆怎么变的，全程看得见。

## 格式

```text
## YYYY-MM-DD HH:MM · distill
- 扫描: N claude / M codex / journal X 天
- 候选: K 条（达标 P · 暂缓 D）

## YYYY-MM-DD HH:MM · promote（你审批）
- 晋升: [c1 → 00-RULES/_principles/xxx.md, …]
- git: <commit>
```
