# 02-SOURCES · 爬回来的资料

> 从外面收进来的原料：文章、工具界面、文档、社媒笔记。agent 写文案/做方案时可直接引用。

- **怎么进来**：装 Obsidian **Web Clipper**（浏览器插件），一键存这里、自动转 markdown。
- **命名**：语义化、小写连字符；建议子目录按主题分。
- **frontmatter** 带 `source`(原始 URL) + `created` + `tags`，方便追溯与召回。
- 边界：能直接被引用的**外部原料**进这里；和某项目绑定的**决定/反馈**进项目层。
