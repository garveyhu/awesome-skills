# Gemini Web UI 地图（gemini.google.com/app）

实测于 2026-06，账号 Gemini Pro，界面中文。UI 会变——**优先用 `find` 按语义定位拿 ref，别死记坐标**；坐标仅作参考（截图 1512×806 时的位置）。

## 整体布局

- 左侧栏：发起新对话 / 搜索 / 库 / Gem / 笔记本 / 最近对话 / 底部账号。
- 主区：欢迎语 + 居中输入框（composer）。
- composer：左「+」(上传和工具) · 中输入框「问问 Gemini」· 右「模型选择(Flash)」+「麦克风」+ 发送时出现的「↑」。

## 工具菜单（点「+」展开）

`find "上传和工具 plus button"` → 点开后菜单项（从上到下）：

1. 上传文件（文档/数据/代码）
2. 从云端硬盘添加
3. 更多上传选项 ›
— 分隔 —
4. **制作图片** ← 图像生成（模型 Nano Banana 2）
5. **制作视频** [新] ← 视频生成（Veo）
6. Canvas
7. 更多工具 ›

`find` 查询示例：`"制作图片 menu item"`、`"制作视频 menu item"`。

## 图像创作视图（点「制作图片」后）

- 顶部："试试用模板创作…" + "使用 Nano Banana 2 生成"。
- 一墙风格模板芯片：单色 / 色块 / 跑道 / 孔版印刷 / 绚彩 / 哥特风黏土 / 轰动 / 沙龙 / 素描 / 电影效果 / 蒸汽朋克 / 日出（点了会套用风格）。
- 底部 composer 占位符变「描述你的图片」，左下有「图片」芯片表示已进入图像模式。
- ⚠️ 坑：进入该视图的瞬间，若在旧位置输入，文字会丢。**等模板墙出现后，对准底部 composer 再输入**。

## 发送 / 等待

- 输入后 composer 右下出现蓝色 **↑ 发送**（约坐标 1197,720；或直接回车）。
- 发送后顶部出现「正在创建您的图片」，对话 URL 变为 `/app/<id>`。
- 轮询：`computer wait`(≤10s/次) + `screenshot`，图约 15–30s 渲染完；视频更久（1–3 分钟）。

## 产物上的操作按钮（`find` 可拿到）

- **「下载完整尺寸的图片」** ← Gemini 自带按钮，**别用 automation 点**（手势门控，必失败）。取原图改用 SKILL.md「取产物到磁盘」的 canvas + `<a download>` 法（程序化即可落盘，无需用户手点）。
- 「分享图片」
- 「显示更多选项」(三点菜单)

## 已知坑汇总

1. **别点 Gemini 自带下载按钮**：扩展点击非 `isTrusted`、无用户激活，它走 File System Access/手势门控，被 Chrome 拦 → 下载失败。**改用 canvas + `<a download>` data-URL 自抓**（同源 blob 图不污染 canvas，普通 `<a download>` 不受手势门控，程序化点击即落盘到 `~/Downloads`，再 `mv` 到目标）。实测 2026-06 跑通 1024×572 原图。
2. **输入丢字**：图像/视频视图切换瞬间输入会丢，等视图稳定再输底部 composer。
3. **原生保存对话框**：若下载弹出 OS「保存到哪」对话框，automation 够不到，交用户处理；别尝试自动操作 OS 对话框。
4. **别复用用户标签页**：新会话 `tabs_create_mcp` 开新标签页；导航 gemini.google.com/app 复用登录态。
5. **截图存盘只有屏幕分辨率**：`save_to_disk` 截图适合快速预览/小图，要原图必须用户点下载；视频无法靠截图存整段。
