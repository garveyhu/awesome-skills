# LoRA 训练要点（速记）

> 训练本身建议在 CUDA 机器上跑（Mac 训练慢且兼容性差）；这里只记可迁移的**方法论**，方便准备数据集与配参。

## 数据集

- 数量：10–15 张可起步，20–30 较优，50+ 更稳。覆盖多角度、表情、光照、服装。

## 打标规则（最关键，决定成败）

1. **永远前缀一个唯一触发词**（`ohwx_x` / `sks_x`），别用通用词。
2. **不要描述脸**——让模型自行学习身份；但**要描述其它一切**（服装、姿势、背景、光照、风格）。
3. 标注结构统一：`[触发词],[主体],[服装],[姿势],[场景],[光照],[风格]`。

## 步数 / 学习率

- 步数 ≈ (图数 × repeats × epochs) / batch。SDXL ≈ 1500–3000。
- **FLUX 收敛快 2–3 倍**（1000–2000 步），学习率更高(4e-4 vs 1e-4)，更早出现过拟合，注意盯。
- 文件夹命名约定：`{repeats}_{触发词}`，如 `10_my_char`。

## 过拟合迹象 → 处理

- 无论提示词如何，姿势/表情都一样；训练集背景渗出；忽略服装/场景提示 → 减 epochs/dim、加数据、增加标注多样性。
- **3D 渲染→写实**技巧：先把渲染图转成多种风格（60% 变体 / 40% 原图），让模型学到的是身份而非"3D 质感"。

## 用 LoRA 生成

ComfyUI 里用 `LoraLoader`（出 MODEL+CLIP）或 `LoraLoaderModelOnly`，**必须接在采样器之前**。强度 0.6–1.0 常用；与底模搭配试。
