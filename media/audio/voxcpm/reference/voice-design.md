# 音色设计 · 方言 · 长稿编排

## 怎么写 `--instruct`（音色描述）

design 模式靠一句自然语言描述「凭空」造出音色，描述越具体越稳。建议覆盖几个维度（中文写即可）：

- **性别 + 年龄**：年轻女性 / 中年男性 / 老年男性…
- **音色质感**：温柔甜美 / magnetic 低沉 / 清亮干净 / 沙哑 / 童声
- **语气情绪**：沉稳 / 活泼 / 严肃 / 亲切 / 兴奋
- **场景人设**：纪录片旁白 / 新闻播报 / 带货主播 / 故事讲述 / 客服

例：
```
--instruct "沉稳磁性的中年男性，纪录片旁白，语速偏慢"
--instruct "活泼的年轻女性带货主播，语气热情，节奏快"
--instruct "温柔的女声，讲睡前故事，轻柔舒缓"
```

同一个 `--instruct` 在不同句子上音色基本一致 → **给频道定一个固定音色**：把这句描述记下来，整期视频都用它配音。

## 中文方言 / 多语言

VoxCPM2 覆盖 30 语言 + 多种中文方言（粤语 / 四川话 / 东北话 / 吴语等）。两条路：

1. **写进 instruct**：`--instruct "用四川话，热情的中年男性"`。
2. **直接给方言文本**：文本本身就用方言用词/语序时，模型会顺势走方言韵律。

外语同理：文本写对应语言即可（英日韩等），无需切模型。

## 参数调优

| 想要 | 调法 |
|------|------|
| 更快（批量长稿） | `--timesteps 5~7`；必要时 `--model mlx-community/VoxCPM2-4bit` |
| 更高质量（精修单句） | `--timesteps 16~20`；`--model ...-bf16` |
| 更贴指令音色 | 适当升 `--cfg`（2.0 → 2.5），过高会僵硬 |
| 段落更连贯 | 升 `--max-chars`（120 → 200），单段更长但更慢 |

## 长稿编排（5 分钟级旁白）

1. 文案写进 `script.txt`，**标点规范**（句号/问号/感叹号到位，模型按句切分靠它）。
2. `say` 或 `design` + `--text-file script.txt`，脚本自动逐句生成、段间插 0.25s 静音拼接。
3. 想分段控制（不同段不同音色 / 插入停顿）：把稿子拆成多个文件分别生成，再用音频工具拼。
4. 速度预期：design/say RTF ≈ 0.4~0.5 → 5 分钟旁白约 2~3 分钟出。

## 声音克隆技巧

- **参考音**：5~15 秒干净人声最佳，无背景音乐/噪声；wav 优先。
- **`--ref-text` 必须是参考音的逐字转写**，错字会带偏音色。
- clone 每句都要编码参考音、**偏慢（RTF ≈ 3）**：长稿成本高。若只是要「某种风格音色」而非复刻特定人，优先用 design。
- 要长稿 + 固定克隆音色：可先 clone 出几句作为风格锚点，再评估是否值得整稿 clone。

## 产物

- 48kHz / 单声道 / float WAV。
- 默认落 `voxcpm_outputs/<mode>-<时间>.wav`；`--out` 指定路径。
- 要 MP3/AAC 或并轨视频：用 ffmpeg 后处理（本 skill 只出 wav）。
